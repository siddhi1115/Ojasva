# Ojasva 

Ojasva is a website I created to help Indian households understand their electricity consumption better.

## About the Project

Usually, our electricity bills show the total amount of electricity used, but we don't really know how much each appliance consumes. With Ojasva, the idea is to make appliance-wise energy consumption easier to understand so people can manage their electricity usage and bills better.

## What Ojasva Aims to Do

- Show electricity consumption appliance-wise.
- Help users understand their electricity usage.
- Make it easier to manage electricity bills.
- Encourage people to save energy and money.

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Google Gemini API

## My Goal

I wanted to work on a problem that people face in their everyday lives. Through Ojasva, I aim to make people more aware of their electricity usage and help them make better decisions.
